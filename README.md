 GreenCart – Online Grocery Shopping Platform

GreenCart is a modern and user-friendly e-commerce web application designed to make online grocery shopping simple and convenient. The platform provides a clean UI, fast performance, product browsing, cart management, and smooth checkout flow. It showcases strong full-stack development skills using React and Tailwind CSS on the frontend.

 Features:

 Product Browsing – View and explore available grocery products.

 Search & Filter – Quickly find products.

 Add to Cart – Add items, update quantity, or remove items easily.

 User Authentication – Secure login & signup system.

 Order Workflow – Full cart and ordering experience.

 Responsive UI – Works smoothly on mobile, tablet, and desktop.

 Fast & Clean Interface – Built for smooth user experience.

 Seller Dashboard (optional) – Manage products and inventory.
